# 🍺🎲 飲んで人生ゲーム

飲みゲー × 人生ゲームのブラウザゲームです。サイコロで人生を進め、止まったマスで飲んだり稼いだりします。
スマホ複数台で遊べて、アプリのインストールもサーバーも要りません（GitHub Pages に置くだけ）。

- 1〜6のサイコロでマスを進む（全26マス、1人あたり約6〜8ターン）
- 学生 → 社会人 → 家庭 → 老後 → ゴール（大往生）の人生コース
- 「？」マスではハプニングカード（22種類）をランダムに引く
- チャレンジマスは成功・失敗をみんなで判定（イッキできたら6マス進む など）
- ゴール順にボーナス。全員ゴールしたら総資産で順位決定、最下位は罰ゲーム
- 酒豪賞（いちばん飲んだ人）も発表

## 遊び方

1. 1人（ホスト）がURLを開き、名前を入れて「部屋を作る」
2. 表示されたQRコード／招待URLを、他の人がスマホで開いて「参加する」
3. スマホがない人は、ホストの端末に「この端末に追加」で参加できる
4. ホストが「ゲームスタート」。自分の番の人の画面にサイコロボタンが出る

> ホストの端末がゲームを管理しています。ホストがページを閉じると部屋も閉じます
> （再読み込みならそのまま復元されます）。参加者は再読み込みしても自動で再接続されます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの `index.html` `style.css` `game.js` `app.js` をアップロード
   （GitHub の画面で「Add file → Upload files」にドラッグするだけでOK）
3. リポジトリの **Settings → Pages** を開き、
   Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で誰でも遊べます

コマンドで置く場合：

```bash
git init && git add index.html style.css game.js app.js README.md .gitignore
git commit -m "飲んで人生ゲーム"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

## マス・イベントを変えたい

`game.js` の `BOARD`（マス）と `HAPPENINGS`（ハプニングカード）を編集するだけです。
効果は `fx` に書きます。

| 書き方 | 意味 |
|---|---|
| `{ d: 'self', n: 2 }` | 自分が2口（`n: IKKI` でイッキ） |
| `{ d: 'others', n: 1 }` / `{ d: 'all', n: 1 }` | 自分以外 / 全員が飲む |
| `{ d: 'pick', n: 2 }` | 指名した人が飲む |
| `{ d: 'pickAndSelf', n: 2 }` | 指名した人と自分が飲む |
| `{ d: 'richest', n: 2 }` / `{ d: 'poorest', n: 2 }` | いちばんお金持ち / 貧乏な人が飲む |
| `{ m: 30 }` | 自分のお金 +30万（マイナスも可） |
| `{ mFromOthers: 10 }` | 他の全員から10万ずつもらう |
| `{ mToPoorest: 10 }` | いちばん貧乏な人に10万あげる |
| `{ skip: 1 }` | 1回休み |
| `{ move: 6 }` | 6マス進む（`-2` で戻る） |

チャレンジマスは `challenge: { q: '質問', ok: [成功時の効果], ng: [失敗時の効果] }` で作れます。
マス数を変えた場合は `GOAL`（ゴールのマス番号）も合わせて変えてください。

## しくみ

- 通信は [PeerJS](https://peerjs.com/)（WebRTC）で端末同士を直接つなぎます。接続の仲介には PeerJS の無料公開サーバーを使います。
- 一部のモバイル回線や社内Wi-Fiなどでは P2P がつながらないことがあります。その場合は同じWi-Fiにつなぐか、ホスト端末に「この端末に追加」で全員入れて1台で回してください。

## 注意

20歳未満の飲酒は法律で禁止されています。「1口」「イッキ」はソフトドリンクや水でもOK。無理せず、イッキの強要はやめましょう。
